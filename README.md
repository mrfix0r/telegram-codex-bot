# Управление Codex через Telegram

Приватный Telegram-бот для управления локальными задачами Codex. Бот принимает команды только от разрешённых Telegram ID, запускает Codex App Server на этом компьютере и присылает ответы, вопросы и запросы подтверждения обратно в чат.

## Возможности

- создание и продолжение задач Codex;
- подключение существующей задачи по Thread ID;
- просмотр статуса и последних задач;
- остановка активного выполнения;
- ответы на вопросы и подтверждение действий Codex;
- сохранение выбранного Thread ID между перезапусками;
- автоматическое обновление меню команд Telegram.
- автоматические повторы при кратковременных обрывах HTTPS-соединения.

Заметок, локальных списков дел и произвольных команд из `actions.json` в боте больше нет.

## Запуск

Нужны Python 3.11 или новее и локальный Codex CLI, уже авторизованный под вашей учётной записью.

1. Скопируйте `.env.example` в `.env`.
2. Скопируйте `.secrets/telegram.env.example` в `.secrets/telegram.env`.
3. Укажите свой Telegram ID в `TELEGRAM_OWNER_IDS` внутри `.env`.
4. Запишите токен BotFather как `TELEGRAM_BOT_TOKEN` в `.secrets/telegram.env`.
5. Запустите бот:

```powershell
python bot.py
```

После запуска отправьте `/start`. Файл с токеном исключён из Git. Переменная окружения `TELEGRAM_BOT_TOKEN`, если она задана, имеет приоритет над локальным секретом.

## Команды

```text
/codex текст             создать или продолжить задачу Codex
/codex_new текст         создать отдельную задачу Codex
/codex_reply текст       продолжить или направить выбранную задачу
/codex_status            показать статус и последний результат
/codex_threads [число]   показать последние задачи Codex
/codex_use ID            подключить существующую задачу
/codex_stop              остановить активное выполнение
/codex_approve           разрешить запрошенное действие один раз
/codex_approve session   разрешить аналогичные действия до конца сессии
/codex_decline           отклонить действие
/codex_answer текст      ответить на вопрос Codex
/help                    показать справку
```

Пример новой задачи:

```text
/codex Проверь проект, исправь ошибки и запусти тесты
```

Итог придёт отдельным сообщением. Пока задача выполняется, её можно направить через `/codex_reply`, проверить через `/codex_status` или остановить через `/codex_stop`.

Чтобы продолжить задачу из Codex desktop или CLI:

```text
/codex_threads
/codex_use THREAD_ID
/codex_reply Продолжай работу и подготовь итог
```

## Безопасность

Бот использует локальный `codex app-server` по stdio и не открывает сетевой порт. По умолчанию действует политика подтверждений `unlessTrusted`: потенциально опасные действия требуют ответа в Telegram. Используйте `/codex_approve session` только тогда, когда готовы разрешить аналогичные действия до конца текущей сессии.

Доступ проверяется одновременно по `TELEGRAM_OWNER_IDS` и, если заполнено, по `TELEGRAM_ALLOWED_CHAT_IDS`.

## Настройки Codex

Основные значения находятся в `.env`:

```text
BOT_CODEX_EXECUTABLE=codex
BOT_CODEX_WORKSPACE=.
BOT_CODEX_MODEL=
BOT_CODEX_APPROVAL_POLICY=unlessTrusted
BOT_CODEX_REQUEST_TIMEOUT=30
```

Пустое значение `BOT_CODEX_MODEL` использует модель из локальных настроек Codex. `BOT_CODEX_WORKSPACE` задаёт рабочую папку для задач. Если команда `codex` отсутствует в `PATH`, бот автоматически ищет CLI внутри локальной установки Codex Desktop на Windows. Явный полный путь в `BOT_CODEX_EXECUTABLE` нужен только для нестандартной установки.

## Проверка

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
```

Состояние выбранных Codex-задач хранится в `data/bot.db`. Старые таблицы заметок и списков дел в уже существующей базе автоматически не удаляются, но код бота их больше не читает и не изменяет.
