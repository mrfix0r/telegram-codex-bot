# Внутренний инструмент через Telegram

Приватный Telegram-бот для быстрых рабочих команд. MVP умеет вести задачи и заметки, показывать статус и запускать только заранее разрешённые локальные действия.

## Что уже работает

- доступ только для ID владельца;
- локальная SQLite-база без отдельного сервера;
- `/todo`, `/todos`, `/done` для задач;
- `/note`, `/notes` для заметок;
- `/run` для разрешённых действий из `actions.json`;
- ограничение рабочей папки, таймауты и запуск без shell;
- автоматическая регистрация меню команд в Telegram;
- восстановление long polling после сетевых ошибок.

## Быстрый запуск

Нужен Python 3.11 или новее. При установке Python на Windows включите опцию добавления `python` в `PATH`.

Установка отдельного пакета `tzdata` не требуется: для `Europe/Moscow` предусмотрен встроенный резервный часовой пояс UTC+03:00.

1. Откройте в Telegram `@BotFather`, выполните `/newbot` и получите токен.
2. Скопируйте `.env.example` в `.env`.
3. Скопируйте `.secrets/telegram.env.example` в `.secrets/telegram.env`.
4. В `.env` заполните `TELEGRAM_OWNER_IDS`, а токен запишите как `TELEGRAM_BOT_TOKEN` только в `.secrets/telegram.env`.
5. При необходимости скопируйте `actions.json.example` в `actions.json`.
6. Запустите:

```powershell
python bot.py
```

После запуска отправьте боту `/start`.

`.secrets/telegram.env` исключён из Git. При развёртывании значение можно передать через переменную окружения `TELEGRAM_BOT_TOKEN`; она имеет приоритет над локальным секретом.

## Команды

```text
/todo текст             добавить задачу
/todos                  показать открытые задачи
/todos all              показать все задачи
/done ID                завершить задачу
/note текст             сохранить заметку
/notes [число]          последние заметки
/actions                список разрешённых действий
/run имя [аргументы]    выполнить действие
/reload                 перечитать actions.json
/status                 состояние инструмента
/ping                   проверка связи
```

## Настройка внутренних действий

`actions.json` не коммитится, потому что в нём могут быть локальные пути. Пример:

```json
{
  "daily-report": {
    "description": "Сформировать ежедневный отчёт",
    "command": ["python", "scripts/daily_report.py"],
    "cwd": ".",
    "timeout_seconds": 60,
    "accepts_arguments": false
  }
}
```

После изменения файла отправьте `/reload`. Команда выполняется как массив аргументов с `shell=false`. Поле `cwd` не может указывать за пределы `BOT_WORKSPACE_ROOT`. Аргументы пользователя запрещены по умолчанию; включайте `accepts_arguments` только для скриптов, которые сами валидируют входные данные.

## Проверка

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
```

База создаётся в `data/bot.db`. Для резервной копии остановите бота и скопируйте папку `data`.

## Следующее расширение

Новые бизнес-команды лучше добавлять отдельными обработчиками в `src/internal_bot/app.py`, а повторяемые локальные сценарии — небольшими скриптами и записями в `actions.json`. Не добавляйте универсальную команду для произвольного shell: Telegram-токен в таком случае становится удалённым доступом к компьютеру.
